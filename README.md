📖 Шо это вообще такое?

Слушайте, это не «корпоративный портал» и не «платформа для бизнеса». Это просто сайт-визитка. Обычный такой, с неоном, музыкой и кнопками, которые что-то делают. Или не делают — проверяйте сами.

Я тут понапихал всего понемножку: визуализатор музыки, звёздочки, летающие точки, баннеры, которые вылезают откуда не ждали. И да, это всё работает. Ну, по крайней мере, я так думаю.

🚀 Как запустить (если вдруг захочется)

1. Склонируйте этот шедевр:
   ```bash
   git clone https://github.com/iemes32/iemes32.github.io.git
   ```
2. Откройте index.html в браузере. Всё. Да, так просто.
3. Если хотите поменять текст — ищите CONFIG в начале скрипта. Там всё подписано.

---

⚙️ Шо можно поменять (ну, типа настройки)

Всё в одном месте — в объекте CONFIG:

```javascript
const CONFIG = {
  name: 'Ваше имя',            // ну, тут имя
  title: '✦ Ваш тег ✦',        // шо вы там хотите написать
  avatar: 'ссылка_на_аватар',  // ваша рожа
  music: 'ссылка_на_музыку',   // шо играть
  socials: [                   // куда ведут кнопки
    { name: 'Telegram', url: '#', icon: '<img ...>' }
  ],
  about: {                     // раздел "Обо мне"
    title: 'Обо мне',
    text: 'Ваш текст',
    media: 'фото или видео'
  },
  projects: [                  // ваши проекты
    {
      title: 'Название',
      description: 'Описание',
      link: 'https://...',
      image: 'скриншот'
    }
  ]
};
```
